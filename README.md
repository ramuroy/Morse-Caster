# 📡 **Morse Caster using Arduino**  

The **Morse Caster** is an **Arduino-based Morse Code Transmitter** that converts text input into **Morse code** and transmits it using an **LED** and a **buzzer**. The transmission is also displayed in real-time on a **16x2 LCD display**, making it a fun and educational project for learning Morse code and embedded systems.  

---

## 🛠️ **Components Used**  
- 🔹 **Arduino Uno** – Processes input and controls output.  
- 🔹 **16x2 LCD Display** – Displays the text and Morse code.  
- 🔹 **Buzzer** – Emits sound corresponding to Morse code.  
- 🔹 **LED** – Blinks according to Morse code signals.  
- 🔹 **Push Button** – Used to input text manually.  

---

## ⚙️ **How It Works**  
1️⃣ The **user inputs text**, which is converted into Morse code.  
2️⃣ The **LED blinks** and the **buzzer beeps** according to the Morse sequence.  
3️⃣ The **Morse code and original text** are displayed on the **16x2 LCD screen**.  
4️⃣ The system automatically **pauses between words and resets** for new input.
